# Changelog

## 0.0.10.8 — 2026-09-08

### Fixed
- `web1x.py`: добавлен отсутствовавший static route `/editor.js` — страница `/editor` подключала `<script src="/editor.js">`, но сервер его не отдавал (404), поэтому редактор не работал вообще.
- `public/hosts_info.js`, `public/editor.js`: удалён вызов `renderSummary(...)` — этой функции нет ни в одном файле проекта. Вызов кидал `ReferenceError` и обрывал `load()` раньше времени: на `/hosts_info` список узлов никогда не отрисовывался, на `/editor` не заполнялись `hosts_editor`/`defaults_editor`/`playbook_editor`.
- `web1x.py`: пагинация `/log_new` ломалась после ~1000 записей в логе, потому что `del LOG[:-1000]` сдвигал индексы, а клиент считал их абсолютными. Добавлен `LOG_OFFSET`, через который `start`/`next` теперь считаются в абсолютных координатах независимо от обрезки списка.
- `public/editor.html`: файл на ~91% состоял из нулевых байт (артефакт архивации/выгрузки); содержимое перезаписано без них, разметка не менялась.

### Removed
- `web1x.py`: удалён фактически неиспользуемый `import socket` (в предыдущем changelog заявлялось, что он уже удалён, — на деле нет).

### Known inconsistencies (не тронуто в этом проходе)
- `main.js` (`renderTemplateTabs`) поддерживает создание узла по всем 5 шаблонам из `template_schemas`, а `hosts_info.js` (`getNodeSchemas`) — жёстко только `host`/`md`; узлы типа «СИ» на `/hosts_info` создать нельзя.
- `hosts_info.js` при создании узла отправляет в `/add_host` поле `node_type`, которое сервер не читает.
- `classify_node()` (web1x.py) классифицирует узел по количеству ключей, а не по их составу — при 5 параметрах узел всегда «МД шаблон-2».

## 0.0.10.7 — 2026-09-08

### Fixed
- Исправлен маршрут `/hosts_info.js`: сервер теперь отдаёт `public/hosts_info.js`, а не `public/editor.js`.
- Удалены устаревшие static routes для несуществующих файлов `5x-fixes.*`, `3x-fixes.*` и `status-fix.js`.

### Refactored
- Удалён неиспользуемый `navHTML()` из `public/common.js`.
- `injectNav()` больше не выполняет бессмысленную установку пустого HTML в `#nav`.
- Удалены дублирующие обработчики `toggleRoleDir()` и `togglePlaybookRoles()` из `public/main.html`; обработка ролей централизована в `common.js`.
- Удалён дублирующий `smoothPanel()` из `public/main.html`; анимация панелей ролей выполняется централизованно.
- Из `web1x.py` удалён неиспользуемый импорт `socket`.

### Audit
- Добавлена `CODE_AUDIT.md` с описанием функций и результатами ревизии.
- Сохранены защитные функции `safe()` и `role_file()` и безопасный запуск `ansible-playbook` без `shell=True`.

### Compatibility
- Поведение API и существующие endpoint'ы сохранены.
- Изменения ограничены исправлением неверной раздачи JS, удалением мёртвых маршрутов и устранением дублирующей клиентской логики.
